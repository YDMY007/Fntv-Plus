# 方案 B：腾讯云开发 CloudBase（国内直连版）

接口与 Cloudflare 版**完全一致**，客户端只改 endpoint 一行，不用动任何代码。

- 云函数：`functions/fntv-stats/index.js`
- 数据：云开发数据库（文档型）两个集合 `ping` / `feedback`
- 入口：HTTP 访问服务，默认域名 `https://{envId}.service.tcloudbase.com`

---

## 一、资费：资源点（2026-09 核实，以控制台/购买页为准）

CloudBase 现在按**资源点**统一计费，**1000 点 ≈ ¥1**，数据库、云函数、存储、流量共用一个池子：

| 资源 | 换算 |
| --- | --- |
| 数据库调用 | **200 点 / 万次** ← 最贵，省它就是省钱 |
| 云函数调用 | 13 点 / 万次 |
| CDN 流量 | 210 点 / GB |

| 套餐 | 价格 | 资源点 |
| --- | --- | --- |
| 免费体验版 | **¥0/月** | 3,000 点/月（1 个环境；**不能加资源包/按量**，超了就停） |
| 个人版 | ¥19.9/月（限时优惠） | 40,000 点/月（可加资源包、可超量按量） |
| 标准版 | ¥199/月 | 330,000 点/月 |

> 省钱关键结论：**数据库调用比云函数调用贵 15 倍**，所以本方案的核心优化全在"少碰数据库"。

## 二、省钱三招（已内置在实现里）

1. **内存聚合批量写**：心跳先进函数实例内存，攒够 50 条或距上次落库 30 秒才批量写一次 → 数据库调用降到 1/50（冒烟实测：50 次心跳只产生 1 次数据库写入）。
2. **内存去重**：同一实例内重复 aid+day 直接返回，零数据库开销；落库用 `_id = aid_day`，重复写会失败并被忽略，天然幂等。
3. **日志不另开存储**：反馈日志正文直接存 `feedback` 文档的字段里（单文档 16MB 上限，我们封顶 3MB），省掉云存储的容量与流量费。

代价：实例被回收时最多丢几十条心跳 —— 统计人数这种场景完全无所谓。

## 三、成本估算（聚合生效后）

| 日活 | 月请求 | 资源点/月 | 落在哪个套餐 |
| --- | --- | --- | --- |
| 1,000 | 3 万 | 约 50 点 | 免费版（¥0）余量充足 |
| 10,000 | 30 万 | 约 500 点 | 免费版（¥0） |
| 50,000 | 150 万 | 约 2,500 点 | 逼近免费版上限 → 建议个人版 ¥19.9 |

保守口径（若批量写入被按 N 条计次）：3 万次/月 ≈ 6,000 点 → 需要个人版 ¥19.9/月。**先用免费版跑一个月看账单明细**，按实际再决定要不要升。

## 四、部署（控制台，约 15 分钟）

1. **开通环境**：腾讯云控制台 → 云开发 CloudBase → 新建环境（选免费体验版先跑；数据库选**文档型**）。
2. **建集合**：数据库 → 新建集合 `ping` 和 `feedback`（权限建议"仅管理端可读写"，我们只通过云函数访问）。
3. **装依赖**：本地 `cd functions/fntv-stats && npm i`（会装 `@cloudbase/node-sdk`）。
4. **建云函数**：云函数 → 新建 → 函数名称 `fntv-stats` → 运行环境 Node.js → 提交方式选**本地上传文件夹/ZIP**（必须连 `node_modules` 一起传）→ 内存选 **128MB**、超时 3s。
5. **环境变量**：函数配置 → 环境变量加 `STATS_TOKEN`（自己想个长口令，看数据用）。
6. **HTTP 访问服务**：环境配置 → HTTP 访问服务 → 新建"域名关联资源"，关联资源选 `fntv-stats` 云函数，域名用默认域名，触发路径**建 4 条**：
   `/ping`、`/feedback`、`/stats`、`/stats/log`。
   （若控制台提供「路径透传」，配一条 `/` 即可，代码按 `event.path` 分发。）
7. **拿地址**：`https://{envId}.service.tcloudbase.com`。

## 五、客户端接入（一行）

`src/main/handlers/plugins/usageStats.ts` 顶部：

```ts
const DEFAULT_ENDPOINT = 'https://{envId}.service.tcloudbase.com';
```

`/ping`、`/feedback` 路径不变，其余代码零改动。看数据：`https://{envId}.service.tcloudbase.com/stats?token=你的口令`。

## 六、注意

- **默认域名只适合开发测试**：官方文档明确它有访问频率限制、有效期限制（到期需到控制台「续期」，5 分钟生效）和稳定性风险。要长期稳定跑，绑定**已备案**的自定义域名。
- 免费体验版**不能买资源包**，超配额直接停服 → 量上来就升个人版。
- 首次调用有冷启动（几百毫秒～1 秒），对"每天一次的统计上报"没有影响。
- 隐私口径与 Cloudflare 版一致：不读不存 IP、不读 UA，只存 aid/版本/系统/架构/日期；日志在客户端已脱敏。
