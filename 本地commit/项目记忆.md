## FN ID 登录（src/main/handlers/plugins/fnid_login.ts）
- 独立 `oauthWindow`(`partition: persist:fnid-oauth`) 加载 `https://5ddd.com/{fnId}` → JS 拦截 XHR `/oauthapi/authorize` 抓 code → 换 token→`saveConfig`→复制 NAS cookie 到 `persist:fntv`→`mainWindow.loadURL(/v)`。
- 持久化关键点：① `saveConfig` 加 `loginType:'fnid'`；② `restoreCookies` 必须带 `expirationDate`（否则成 session cookie 重启丢失）；③ `/v/login` 拦截器 `clearLoginCookies(keepToken=true)` 保护 token，否则重启被清空永远无法恢复。FN ID 无静默刷新，cookie 过期需重新 OAuth。

## PotPlayer 外部播放器（核心功能，2026-07-24~25）
- `PlayerType.POTPLAYER` + `impl/potplayer.ts`：spawn 拉起。
- 能力：续播 `/seek`；外挂字幕 `/sub`；`potctl.exe`(Go, `src/modules/proxy/potctl/main.go`) 每 5s `SendMessageW(hwnd,WM_USER(0x400),命令码,0)` 读进度(state: -1停/1暂停/2播放；-1 在 WoW64 零扩展成 0xFFFFFFFF，按 int32 还原)→`PROGRESS`→`recordPlayStatus` 写回续播；逐集拉起+本集播完自动连播下一集（potctl 缺失降级 m3u8 连播）。常量 20482/20484/20486 在 main.go 顶部。
- 配置隔离：内置 PotPlayer 复制到 `userData/potplayer` + 空 `PotPlayerMini64.ini` 触发 ini 便携模式，绝不碰本机注册表。`getPotPlayerPath` 三级：用户路径 > userData 副本 > 本机安装。`isPotPlayerBundled()` 供 UI 显示"应用内置"。
- 弹幕现行方案(v4，最稳)：翻译字幕+弹幕ASS【合并成单个ASS】用单 `-sub=` 加载，不依赖双字幕开关。根因：PotPlayer 无 `/sub2` 参数，v3 用 `-sub2` 被忽略→弹幕不显示。`subtitleMerge.ts` 解析合并，强制 `PlayResX/Y=1920x1080`，内容嗅探(扩展名≠内容时按含[Events]+Dialogue: 判 ASS)；翻译解析失败降级为仅弹幕单轨。播放秒开：先 spawn 后 `attachSubtitle` 用 `/current` 窗口内重载挂幕(6s 超时保护)。
- 点播切换：同 PotPlayer 用 `/current` 转发复用窗口切集；不同类型/失败则 stop+重建。

## MPV 着色器/ICC（设置面板管理，2026-07-25）
- 默认无着色器 + ICC 开。面板 `<select>`(10档 off/a/b/aa/bb/lite/denoise/real/cinema/ultra)+checkbox → `settings:set-mpv-shader-config` → `writeMpvUserConfig` 写 `portable_config/mpv-user.conf`（`mpv.conf` 的 `include=~~/mpv-user.conf` 加载）。`MPV_SHADER_PRESETS` 在 mpvConfig.ts 与 input.conf Ctrl+1~9 一致。
- 打包态路径坑：`app.isPackaged` 时 `getPortableConfigDir` 改用 `path.dirname(app.getPath('exe'))`（asar 只读）；dev 用 `app.getAppPath()`。
- MPV 黑屏真因：`vf=deband=iterations=...` 非法（lavfi deband 参数名是 1thr/2thr…，非 iterations/threshold）→ 滤镜创建失败崩视频链→黑屏有声音。`hwdec=auto-copy` 在用户机器可用（非黑屏因）。`persist_mpv.lua` 已删除（改面板管理）。
