# Fntv-Plus 更新日志

## v3.5.0 (2026-08-25)

> 本次更新以稳定性与体验优化为主，重点新增「手柄控制」与「影视观影记录」两项功能，并修复若干已知问题。

### ✨ 新功能 / 体验改进
- **新增手柄控制**：支持使用游戏手柄在应用内导航与操控播放。
  - **焦点导航**：以高亮白框替代鼠标指针，方向键移动焦点、A 键确认（等效点击），无需鼠标即可完成界面操作。
  - **媒体控制**：通过手柄即可控制播放 / 暂停、快进快退、音量等。
  - **自定义映射**：设置面板新增「手柄」分类，可对手柄按键进行个性化映射。
- **新增影视观影记录**：新增「观影记录」面板，集中回顾你的观看足迹。
  - **分区展示**：按「已看完 / 在观看」分区，含封面、标题、总时长与最后观看时间。
  - **评分展示**：已打分的作品在封面标题上方显示五角星评分。
  - **观影活动热力图**：支持 年 / 季 / 月 / 周 多范围切换，直观呈现每日观看活跃度（正方形小格子，无数据日期以浅白占位）。
  - **详情跳转**：在作品详情页点击「查看详情」可直接跳转至飞牛影视内对应作品详情播放页。

### 🐛 修复
- 修复若干已知问题，提升整体稳定性与界面交互体验。

### 🔧 优化
- **热更新机制完善**：优化完善热更新补丁包安装覆盖机制。
