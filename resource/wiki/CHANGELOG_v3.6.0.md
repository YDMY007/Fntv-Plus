# Fntv-Plus 更新日志

## v3.6.0 (2026-09-06)

> 本次更新重点带来三大体验升级：**全新首页轮播**、**沉浸式剧集详情页（一级 / 二级）**，以及**演员信息页「一键查作品 + 是否入库」**；同时重做播放逻辑与设置面板，并修复若干播放问题。

### ✨ 新功能 / 体验改进
- **全新首页轮播**：默认采用立体堆叠的 3D 旋转木马样式，海报更大更聚焦，切换带有流畅的 3D 纵深动画；也可在设置中切换为滑动、卡片堆叠等其他样式。
- **沉浸式剧集详情页（一级 / 二级）**：剧集页与季页均采用 Netflix 风格的两栏布局——左侧选集、右侧剧集信息与演员墙，并配有全屏背景海报；支持剧照点击放大，可一键补全每集的简介信息。
- **演员信息页「一键查作品 + 是否入库」**：在演员页面新增「TMDB 完整作品」面板，点击即可查询该演员的全部影视作品；每部作品都会标记**是否已收入你的影视库**（库中作品带绿色徽章并可点进详情，未入库作品灰显并提示去 TMDB 查看），还支持「只看未入库」快速筛选。
- **云母增强玻璃质感界面**：全新的磨砂玻璃视觉风格，让界面更具层次感（默认开启，可在设置中关闭）。
- **主界面 Logo 自定义化**：首页顶部 Logo 支持切换为内置的多种海内外流媒体品牌标识（如 Netflix、Disney+、HBO 等），也可自行上传图片，并一键恢复默认。
- **Trakt 观影记录同步**：可将观影记录同步到 Trakt——已看完的电影、已看过的剧集集数，都会写入你的 Trakt 历史，方便跨平台统一记录。
- **自动连播与「下一集」倒计时**：看完一集自动提示并播放下一集，体验对标主流流媒体。
- **智能跳过片头 / 片尾 / 前情**：接入更多数据源，跳过覆盖更广、更准确。
- **设置面板全面升级**：分类更清晰、采用 iOS 风格开关、支持搜索，并新增浅色主题。
- **年度观影报告**：生成可分享的年度总结报告，并可导出为长图。
- **无障碍与多语言**：新增键盘焦点高亮、屏幕阅读支持，并支持简体中文 / 英文切换。
- **安装与卸载界面美化**：采用液体玻璃风格，并加入品牌闪屏动画。

### 🐛 修复
- 修复点击播放弹出「选择播放器」时页面出现白屏闪烁的问题。
- 修复使用 MPV 播放时白屏只有声音的问题。
- 修复在网盘 / 远程环境下播放偶发失败、一直转圈或卡顿的问题（百度、115、SVIP 直链等更稳定）。

### 🔧 优化
- **出厂默认更改**：浅色主题、TMDB 免梯子直连`（强烈建议开启，避免无法获取tmdb数据）`、云母增强均默认开启，开箱即用。
- **视觉风格统一**：全局配色由旧粉紫调整为冷调渐变玻璃风格。
- **播放体验提升**：新增 MPV 画质预设（性能 / 均衡 / 高画质）、进度条悬停预览缩略图、倍速与音量跨集记忆。
- **弹幕接口可自定义**：弹弹 play 获取弹幕支持填写专属 API 凭证，避免因公共接口限流而拉取失败（404）。
- **手动补全集信息**：季页选集支持一键触发补全——当飞牛没能刮到某集的标题 / 简介时，可从 TMDB 重新补回。
- **数据源加载更稳**：跳过与弹幕等外部数据在国内网络下自动优选直连，加载更快更稳。
- **整体更流畅**：修复多处卡顿，操作响应更跟手。
