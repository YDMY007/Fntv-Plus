# 更新日志

## v3.3.4（2026-08-02）

> 本次更新聚焦播放器稳定性与界面体验，修复若干已知问题，并新增 MPV 窗口置顶等功能。

### 🐛 问题修复（11 项）

- **修复设置面板配置 MPV 默认使用着色器不生效导致的卡顿**：修复部分机型勾选 MPV 默认着色器后播放初期卡顿、掉帧的问题，优化着色器配置的加载时机与生效路径，确保画质滤镜正常应用且不拖累解码性能。
- **修复「继续观看」调用 PotPlayer 播放器失败**：修复从「继续观看」入口启动 PotPlayer 时因播放地址与会话鉴权未正确传递导致的启动失败、黑屏报错，现已正确透传会话 Cookie 与可读名播放地址，PotPlayer 可稳定续播。
- **修复 PotPlayer 播放列表集数重复问题**：修复播放列表面板中同一集重复出现、顺序错乱的问题，现按真实集数去重并正确排序，逐集连播更可靠。
- **修复多季剧集详情页页面显示异常**：修复多季（如「第一季 / 第二季」）剧集详情页布局错乱、季切换后信息显示异常的问题，详情页现可正确区分各季内容并稳定渲染。
- **修复手动匹配元数据显示内容超出容器的问题**：修复剧集手动匹配弹窗中文件位置等长路径超出弹窗容器被裁切的问题，弹窗内容现已自适应容器宽度，超长路径可完整显示并支持滚动。
- **修复影视页面弹窗按钮显示异常问题**：修复影视相关弹窗内按钮错位、样式异常或点击无响应的问题，弹窗内交互控件现已正常对齐并可正常操作。
- **修复启用飞牛访问码导致无法进入影视首页**：修复服务端启用「访问码」后进入影视首页卡在授权/空白页的问题，现已在登录与首页加载环节正确处理访问码校验，可顺利进入影视首页。
- **修复侧边栏数字显示异常问题**：修复侧边栏栏目角标（未看数量等）显示异常、数字错乱或不刷新的问题，角标现已正确统计并在内容变化时实时更新。
- **修复特定文档导致软件崩溃重置的问题**：修复打开/解析特定文档时触发软件崩溃、配置被意外重置的问题，增强异常文档的容错处理，避免连带清空用户配置。
- **修复 PotPlayer 播放列表显示 GUID 乱码**：修复播放列表直接显示 item GUID 原始字符串（如 `1d0b8996...`）而非可读剧集名的问题，列表现显示正确的「番名 - 第 N 集」名称。
- **修复使用飞牛影视网页播放导致画面黑屏不显示的问题**：修复部分环境下原生网页播放出现「有声音无画面」黑屏的问题，优化网页播放的合成与渲染路径，画面可正常显示。

### ⚡ 体验优化（3 项）

- **优化设置页面布局**：重排设置页面分区与控件间距，信息层级更清晰；将「弹幕屏蔽」整合为「弹幕设置」并补充弹幕文件管理入口，查找与操作更顺手。
- **优化首页鼠标滚动逻辑**：优化首页卡片墙的鼠标滚轮滚动体验，修正滚动方向、惯性及边界回弹逻辑，长列表浏览更跟手、不再误触翻页。
- **优化 B站弹幕下载逻辑和配置**：放宽同番搬运（简称 / 异译）的相似度下限提升命中率，改为单源取弹幕避免多源合并导致时间轴错位；新增「打开弹幕文件夹」入口便于集中管理，并修复弹幕脚本加载异常导致弹幕整体失效的问题。

### ✨ 新增功能（1 项）

- **MPV 播放器添加窗口置顶功能**：新增 MPV 播放窗口「始终置顶」开关，观看时可让播放窗口停留在最上层，方便边看边操作其他窗口。
