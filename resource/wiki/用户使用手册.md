## 1. 简介与功能一览

Fntv-Plus 是飞牛影视（fnOS TV）的第三方桌面客户端，在浏览器体验之外提供：

- 🌈 **透明亚克力界面** + 深浅色主题切换
- 🎬 **外部播放器**：内置 MPV（默认）、可调用系统 PotPlayer，支持续播与逐集连播
- 🎯 **字幕自动选择**：自动匹配最佳一条中文外挂字幕
- 💬 **B站弹幕**：扫码登录 B站后自动获取对应番剧弹幕
- 📺 **豆瓣同步**：播放进度标「在看」、已观看列表标「看过」
- 📊 **Bangumi 自动点格子**：进度达阈值（默认 80%）自动标该集「看过」
- 🔧 **侧栏设置面板**：实时调节透明度 / 模糊 / 播放器 / 同步等

## 3. 安装

前往仓库 [Releases 页面](https://github.com/YDMY007/Fntv-Plus/releases) 下载对应安装包（命名格式 `Fntv-Plus_版本_平台_架构.后缀`）：

- **Windows**：下载 `Fntv-Plus_*_win_x64.exe`，双击安装，支持自定义安装路径与桌面快捷方式。
- **macOS**：下载 `Fntv-Plus_*_mac_*.dmg`，拖入「应用程序」即可。安装后若提示已损坏，在终端执行：
  ```bash
  sudo find "/Applications/Fntv-Plus.app" -exec xattr -d com.apple.quarantine {} \; 2>/dev/null
  ```
- **Linux**：下载 `Fntv-Plus_*_linux_*.AppImage`，添加执行权限后直接运行：
  ```bash
  chmod +x Fntv-Plus_*_linux_*.AppImage
  ./Fntv-Plus_*_linux_*.AppImage
  ```
  > Linux 下弹幕与播放器配置已内置，MPV 增强（着色器 / 弹幕）仅需自行安装系统 mpv，要求 **mpv 版本 > 0.37.0**。

## 4. 首次连接飞牛影视

启动后需连接到你的飞牛影视服务：

1. **局域网 / 本机**：在连接界面填写飞牛影视地址（如 `http://192.168.x.x:18888`）。
2. **远程访问**：使用 **FN ID 登录** 方式（见第 5 节），通过 FN Connect 远程连接。

> 首次使用建议先在飞牛影视 Web 端用账号登录一次，客户端会复用登录态。

---

## 5. FN ID 远程登录

用于在没有公网 IP 时通过 FN Connect 远程访问飞牛影视：

1. 在飞牛影视 App / 后台开启 **FN Connect**，获取你的 **FN ID**。
2. 在客户端登录界面选择「FN ID 登录」，输入 FN ID。
3. 客户端会弹出独立授权窗口完成登录，登录态会被持久化，支持多账户切换。

> 若远程登录后功能异常（如进度不回传），多为远程登录态过期，重新走一次 FN ID 登录即可。

## 6. 设置面板

点击左侧栏「⚙ 设置」打开居中半透设置面板，主要分组如下：

| 分组 | 可调节项 |
|------|----------|
| **外观** | 窗口透明度、模糊强度、主题（浅色 / 深色 / 跟随系统） |
| **播放器** | 默认播放器（MPV / PotPlayer）、续播与逐集连播、播放链路（302 直链 / NAS 代理） |
| **字幕** | 外挂字幕自动选择开关 |
| **B站弹幕** | 扫码登录 B站、弹幕自动获取、手动搜索 |
| **豆瓣** | 豆瓣 cookie / token 配置、同步开关 |
| **Bangumi** | Bangumi token、同步开关、触发阈值（默认 80%） |
| **调试** | 调试日志级别、按组件过滤、打开 / 导出日志文件 |

设置大多即时生效；播放器与画质相关改动在下一部影片 / 下次启动时应用。

## 7. 播放器使用

### MPV（默认）
- 内置 MPV 播放内核，支持 H264 / HEVC / VP9 / AV1 硬解。
- 进度实时回传飞牛服务器，关闭后下次可续播。
- 快捷键见安装目录 `third_party\fntv-mpv\portable_config\input.conf`。

### PotPlayer（可选）
- 在「设置 → 播放器」中切换为 PotPlayer，客户端会调用系统已安装的 PotPlayer（或内置便携版）。
- 内置 `potctl` 进度助手每 5 秒读取播放进度回写飞牛，实现续播与逐集连播。
- 若进度不回传，请确认「播放器」设置中已开启续播 / 进度回传相关选项。

### 画质增强（MPV）
- 设置面板提供 10 档着色器预设（含 Anime4K）+ ICC 校色开关，选择后即时生效。

## 8. 字幕与 B站弹幕

- **字幕**：播放时自动选择最佳一条中文外挂字幕，MPV 与 PotPlayer 均支持。无需手动操作，无字幕时多为片源本身无外挂字幕。
- **B站弹幕**：
  1. 在「设置 → B站弹幕」中**扫码登录 B站**（仅需一次，登录态会保存）。
  2. 播放番剧时客户端按番名 / 集数自动匹配并加载 B站弹幕。
  3. 匹配失败时，可在弹幕面板**手动搜索**番剧名。
  4. 弹幕功能依赖 Python 运行时：新版安装包已**内置 Python，零配置**；旧版请确保系统已安装 Python 3 且在 PATH 中。

---

## 9. 豆瓣 / Bangumi 同步

### 豆瓣
- **播放进度同步**：观看中自动标记该影视为「在看」。
- **已观看同步**：飞牛「已观看列表」中的影片，自动标记豆瓣「看过」。
- 需在「设置 → 豆瓣」中正确填写豆瓣 cookie / token。

### Bangumi（集数级）
- 播放进度达到阈值（默认 80%）时，自动标记**该集**为「看过」并将条目标为「在看」；播放到末集自动标整部「看过」。
- 需在「设置 → Bangumi」中填写 Bangumi token（需 `write:collection` 权限）。
- 若某番未同步，多为飞牛片名与 Bangumi 条目无法自动匹配，可在设置中手动关联。

## 11. 故障排查

下面按「现象 → 可能原因 → 解决方法」列出常见问题。

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| **窗口透明 / 看不到内容** | 亚克力窗口在部分桌面环境、远程桌面下不渲染 | 打开设置降低「窗口透明度」或在纯色背景下使用；远程桌面场景建议关闭透明 |
| **播放黑屏 / 无画面** | MPV 着色器 / 滤镜配置异常 | 关闭画质增强预设；删除用户数据目录下的 `mpv-user.conf` 恢复默认；确认 mpv 版本 > 0.37 |
| **播放卡顿 / 掉帧** | 网络或解码链路问题 | 在「播放器」设置切换 302 直链 / NAS 代理；检查网络；降低画质预设 |
| **字幕不显示** | 片源无外挂字幕或字幕设置关闭 | 确认影片有外挂字幕；检查「设置 → 字幕」自动选择已开启 |
| **B站弹幕不显示** | 未登录 B站 / 缺 Python / 未匹配 | 先扫码登录 B站；确认内置或系统 Python 可用；手动搜索番名 |
| **进度不回传飞牛** | 播放器或远程登录态问题 | MPV 默认自动回传；PotPlayer 需开启续播；远程登录过期则重走 FN ID 登录 |
| **豆瓣不同步** | cookie / token 失效或无匹配条目 | 重新填写豆瓣 cookie / token；确认影视能匹配豆瓣条目 |
| **Bangumi 不点格子** | token 无权限 / 未达阈值 / 未匹配 | token 需 `write:collection`；进度需达阈值（默认 80%）；手动关联条目 |
| **检查更新失败** | GitHub 直连被限制 | 点击「镜像检查」换镜像源；或稍后重试；确认网络可访问 GitHub |
| **关掉窗口进程还在** | 单实例锁 + 托盘，关窗 ≠ 退出 | 右键托盘选择退出；或任务管理器结束 `electron.exe` |
| **远程访问连不上** | FN ID 错误或 FN Connect 未开 | 核对 FN ID；在飞牛后台确认 FN Connect 已开启；重新 FN ID 登录 |
| **弹幕搜索报 python 错误** | 缺少 Python 运行时（旧版） | 升级到内置 Python 的新版；或系统安装 Python 3 并加入 PATH |

### 通用自救步骤
1. **重启客户端**：彻底退出（托盘退出 / 结束 `electron.exe`）后重新打开。
2. **查看日志**：
   - **软件能打开**：「设置 → 调试」中开启调试日志，点「打开日志文件」直接查看，或点「导出日志文件」另存后发给维护者。
   - **软件打不开（无任何窗口）**：日志仍写在磁盘。按 `Win + R` 输入 `%APPDATA%\fntv\logs` 回车，用记事本打开 `app.log`（另有 `app-日期时间.log` 为历史日志）。若该 `logs` 目录都不存在，说明进程在极早期就崩溃了，请改用「命令行启动看报错」+「事件查看器」定位。
3. **恢复默认配置**：若怀疑是设置导致，可关闭相关增强开关，或删除用户数据目录下的对应配置文件后重试。
4. **确认版本**：到 Releases 页面确认使用的是最新版本，旧版本可能已修复已知问题。

## 12. 卸载

- **Windows**：通过系统「添加或删除程序」卸载；用户数据（配置 / 登录态）位于 `userData` 目录，可手动删除以彻底清理。
- **macOS**：将「Fntv-Plus.app」拖入废纸篓。
- **Linux**：删除对应的 `.AppImage` 文件即可（便携，无残留注册项）。

> 卸载不会自动删除远程飞牛影视服务端的数据，仅移除本机客户端与本地配置。

## 13. 常见问题 FAQ

**Q：我的 B站 / 豆瓣 / Bangumi 账号信息安全吗？**
A：三类凭证均仅保存在你本机的 `userData/config.json` 中（AES-256 加密），不会上传到任何仓库或第三方服务器。

**Q：为什么 Windows 安装包不在自动构建里？**
A：Windows 安装包由维护者手动构建并上传，macOS / Linux 由 GitHub Actions 自动构建。这是项目的发布策略。

**Q：客户端和飞牛影视官方是什么关系？**
A：无任何关系。本项目是第三方客户端，仅为个人练手 / 学习用途，不代表官方立场。

**Q：播放器能换成本机已有的 MPV / PotPlayer 吗？**
A：MPV 使用内置便携配置；PotPlayer 支持调用系统安装版，也可使用客户端内置便携版（配置互相隔离）。
