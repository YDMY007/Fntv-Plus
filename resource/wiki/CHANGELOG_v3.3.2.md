# 更新日志

## v3.3.2（2026-07-27）

> 本版本涵盖 v3.3.1 之后的全部开发提交（lc-109 ~ lc-127）。

### 🎯 1. FN ID 登录（飞牛 ID）外网全面修复

- **外网切换白屏**：修复切到外网后仍用持久化内网 IP 直接连接导致白屏——新增启动域名可达性预检，不可达自动回退登录页（内网仍走内网）。
- **中继选择页可点击**：修复 FN Connect 中继选择页三个选项无法点击，改为窗口内导航）。
- **自动填充健壮化**：修复中继通过后仍需手动再输一次账号密码——用户名/密码/登录按钮改为多级选择器。
- **官方中继转发卡死（根治）**：定位 NAS 实际暴露在子域，改由主进程直接轮询拿配置、绕过页面内 WebRTC 隧道，彻底解决官方中继登录静默卡死。
- **退出重登白屏**：修复登录页强制刷白底；登录页背景图改用绝对URL，退出重登也正常显示。

### 🎨 2. 登录页背景图自定义

- 设置面板「退出行为」下方新增 **「自定义登录页面背景图」** 与 **「清空」** 两个按钮，可选本地图片作为登录页背景，配置持久化（重启生效）。
- 默认登录背景图统一为 `bg-login.jpg`。

### 🌗 3. 深色模式与界面

- **去突兀化**：深色模式下详情页按钮与标题栏进一步收敛为极淡幽灵风（提供自定义关闭按钮。）。
- **亚克力默认值**：首次登录的亚克力透明度 / 背景模糊默认值统一为 30。

### 🐛 4. 其他修复

- **列表页右侧留白**：卡片网格改为确定性居中计算，修复偏右、横向滚动、虚拟滚动反复横跳等问题。
- **播放页劫持问题**：修复特定情况下播放按钮走飞牛原生播放问题，现已可正常调用默认播放器播放。

### ⚡ 5. 性能与体验优化

- **首页刷新策略优化（lc-127）**：原每次关闭视频（含播放器异常退出）都会整页刷新首页，频繁打断浏览体验。现已改为**仅在每次「启动」时随初始加载刷新一次首页**；
