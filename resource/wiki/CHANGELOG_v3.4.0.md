# Fntv-Plus 更新日志

## v3.4.0-full (2026-08-17)

> 本次更新重点上线 **热补丁更新机制**：用户通过弹窗获取补丁后，重载应用即可生效，无需下载全量包覆盖更新；同时修复多项问题并优化界面动画。

### ✨ 新功能 / 体验改进

- **上线热补丁更新机制**：用户通过弹窗获取热补丁（包标识 `-hotfix`）后，重载应用即可生效，无需下载以 `-full` 标识的全量安装包覆盖更新；应用补丁后侧栏 / 关于页版本号同步显示为补丁版本。

### 🐛 修复
- **修复应用补丁弹窗误报「发现新热补丁」**：当已是最新且无新补丁时不再误提示
- **修复关闭向导后遮罩残留、需点两次才退回侧栏**：应用补丁 / 测试更新向导关闭时统一调用退出设置面板，一次性正确退回侧栏，不再残留遮罩层。
- **修复列表页（全部剧集）路由返回后居中失效**：进入多季剧集详情页再退回列表页时，列表居中布局第二次失效的问题已修复（布局锁定机制改为绑定真实 DOM 节点，详情页清除标记时一并清空锁）。
- **修复飞牛影视个人视频库消失问题**：修复个人视频库偶发不显示 / 消失的问题，确保进入影视界面时个人库正常加载。
- **PotPlayer 播放 strm 失败初步修复**：初步修复 PotPlayer 播放 strm 直链失败的情况，提升外置播放稳定性。
- **修复特定情况下详情页显示异常问题**：修复某些情况下详情页布局 / 内容显示异常的问题。
- **优化 B 站弹幕匹配电视剧逻辑**：优化 B 站弹幕对电视剧的匹配策略，减少误匹配与漏匹配。
- **修复特定情况下首页重复刷新问题**：修复某些情况下首页重复刷新的问题，避免重复拉取与闪烁。

### 🔧 其它
- **MPV 插帧新增 N 卡档**：适配 RTX 50 系驱动级 Smooth Motion（呈现上下文 winvk，需在 NVIDIA App 按 exe 注册 `mpv.exe` 并开 SM 后生效）；同步修复此前误用 D3D11 导致无效的问题。
- **优化界面动画**：卡片 / 按钮入场改用 anime.js 引擎（v4.5.0），新增 stagger 错落入场与更顺滑的过渡效果，并保留 CSS 降级兜底保证兼容性。

### 📥 下载指南
| 平台 | 文件类型 | 说明 |
|------|----------|------|
| 💻 Windows | `.exe` | **由维护者手动上传至本 Release**（不通过自动构建） |
| 🍎 macOS | `.dmg` | 磁盘镜像，安装后执行: `sudo find "/Applications/Fntv-Plus.app" -exec xattr -d com.apple.quarantine {} \; 2>/dev/null` |
| 🐧 Linux | `.AppImage` | 便携应用，添加执行权限后直接运行。弹幕与播放器配置已内置，仅需自行安装 mpv（要求版本 > 0.37.0） |
