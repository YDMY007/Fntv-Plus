# 更新日志

## v3.3.1（2026-07-27）

> 本次为**稳定性修复版本**，重点解决 v3.3.0 实测中暴露的启动白屏/卡死、覆盖安装闪退、首页播放劫持与刷新异常等问题。建议所有 v3.3.0 用户升级。

### 🐛 1. 启动与稳定性修复

- **修复白屏卡死（启动即白屏 / 卡死）**：根因为首页轮播「加载占位」与 DOM 变更监听相互触发，形成渲染线程死循环，导致页面永远无法绘制。已加守卫使占位只构建一次，数据到达后再重建真实轮播。
- **修复覆盖安装闪退**：上游旧版（`FNMedia.exe` / `飞牛影视.exe`）与本品共用同一单实例锁，旧进程常驻时新版本抢锁失败被静默退出。现启动前自动清理残留旧版进程，锁仍失败则弹「程序已在运行」明确提示而非秒退。
- **中文安装路径检测升级为「阻断 + 引导重装」**：原仅弹非阻断警告；现检测到安装目录或用户目录含中文 / 非 ASCII 字符时，提示用户更改路径。
- **代理崩溃兜底**：内置代理单请求异常不再拖垮整个代理进程，改为记录日志并返回 502，主进程自动重启代理。

### 🎞️ 2. 首页轮播修复

- **修复主页有数据却不显示轮播**：原选择器写死且要求标题含「媒体库」，部分 fnOS 布局匹配不到 → 轮播缺失。已改为多级兜底查找，兼容不同布局与文案。

### 🎬 3. 播放体验修复

- **修复首页封面播放图标未劫持（走官方网页播放）**：此前直接点首页卡片封面上的播放图标会落到官方网页播放器；现与详情页一致，统一劫持到外部播放器。
- **优化体验关闭视频后首页每次刷新一次**：此前每次关掉播放器都会整页刷新；现仅在「播放器异常退出」时作为崩溃恢复才刷新，正常关闭由页面自身返回，符合良好视觉体验预期。

### 🔇 4. 其他优化

- **屏蔽启动清理残留进程的无害报错**：启动前清理旧版进程时，若目标不存在报错提醒，现已屏蔽该噪声。
