# 项目建立

> 飞牛影视第三方桌面客户端：基于 Electron 深度封装飞牛影视（Fntv-Plus）Web 端，旨在为你提供超越浏览器的桌面体验与丰富增强功能。

## v3.0.0（2026-07-21）

### ✨ 新增

- **客户端 UI 大改**
  - 初次对客户端界面进行大幅度重构与改版，整体视觉与交互焕新

- **飞牛首页轮播大图**
  - 首页新增轮播大图展示，强化影视封面与推荐位的视觉呈现

- **退出托盘与设置整合**
  - 优化退出到系统托盘的行为
  - 将设置相关内容收进飞牛侧边栏，入口更集中、界面更简洁

- **B站弹幕搜索获取（初步）**
  - 初步支持 B站 弹幕的搜索与获取，为后续弹幕能力打底
