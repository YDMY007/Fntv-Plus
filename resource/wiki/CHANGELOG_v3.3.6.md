# Fntv-Plus 更新日志

## v3.3.6 (2026-08-11)

> 本次更新重点新增「切换系统原生页面」与「文件管理器一键外置播放」能力，优化每日放送时间排序并支持点击联动跳库内详情页，同时对首页轮播进行全面改版，并修复了系统页缩略图异常等多项问题。

### ✨ 新功能 / 体验改进
- **新增「切换系统原生页面」能力（重点）**：侧栏一键将整窗从影视界面切到飞牛原生 NAS 系统桌面（文件管理、设置等原生 UI）。可自定义系统页地址（端口各异时填写，留空自动用同端口根路径）；进入系统页后全局亚克力 / 白底清除等视觉改造自动让位，原生外观零污染。
- **文件管理器一键外置播放（重点）**：在飞牛原生系统页（文件管理器）选中视频时，提供显式「外部播放器打开」入口，一键调用 PotPlayer / MPV 直接播放，无需先跳回影视界面；与视频预览「🎬 外部打开」共同构成外置播放双通道。
- **每日放送（Bangumi）列表优化时间排序逻辑，并新增点击联动**：默认按「今天优先」的循环星期分组展示，打开当天即见今日番组（不再固定从周一排起）；可按星期 / 按热度切换，并保留「不感兴趣」剔除与本地屏蔽。**新增联动**——点击卡片时若飞牛影视库内已有该剧，直接站内跳转到对应剧集详情页；库内没有则退回打开 Bangumi / TMDB 外部链接。
- **首页轮播图全面改版**：重构为「左侧背景大图 + 右侧文字信息 + 右侧竖向海报条」布局；海报条与左侧轮播联动（悬停切换、暂停自动播放、选中居中放大），移除旧轮播指示点。
- 新增获取轮播 Logo 固定在海报左下角的透明 TMDB Logo（缺失 tmdbId 时按标题匹配；纯白 Logo 改为最后兜底而非硬性排除）。
- 轮播徽标文案改为集数信息：连载剧显示「全 N 集 · 更新至 M 集」，完整版显示「全 N 集」，电影显示「年份 · 电影」。
- **fnOS 视频预览支持一键外置播放**：预览窗口标题栏新增「🎬 外部打开」按钮，并支持自动弹出选择窗（外置播放器 / 飞牛原生），直链抓取更可靠、不再「选了就播」。
- 设置面板新增「自定义代理」（HTTP/SOCKS5 + 账号密码鉴权 + 测试连接），Bangumi 每日放送 / TMDB 可走用户自建代理；新增「免梯子直连」覆盖 Bangumi 国外源。

### 🐛 修复
- **修复系统页（文件管理 / 设置等原生界面）缩略图变黑框、被放大的问题**：将亚克力 / 液态玻璃的背景与模糊、白底清除、max-width 等全局规则严格限定到影视页，不再污染飞牛原生 UI。
- 详情页 / 列表页布局守护限定为媒体库列表页，修复演员页（/v/person）误套、首页崩溃、详情页时宽时窄 / 左右不对称。
- B站弹幕：番剧匹配优化（国创对称番剧、含「你们」番名误杀）、开发版弹幕失效修复。
- 海报墙在实时数据抓取失败时不再消失（启用硬编码兜底）；轮播图 / 详情页 Logo 持久化磁盘缓存，已加载图片不再反复重拉。
