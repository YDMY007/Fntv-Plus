# 更新日志

## v3.3.3（2026-07-29）

> 本版本主要修复了弹窗按钮消失、首页轮播白屏与误注入等界面异常，优化了 fnOS 连接报错提示与日志体验，并新增首页刷新、侧边栏 QQ 群反馈等小功能，同时提升了 MPV 的 B站弹幕匹配效果。

## 🆕 新增功能

### 🏠 首页手动刷新按钮
- 首页导航栏新增刷新按钮，可一键刷新首页与轮播内容。

### 💬 侧边栏 QQ 群快速反馈入口
- 侧边栏新增「Q群反馈」按钮，一键加入官方 QQ 群，方便反馈问题与日常交流。

## 🐛 修复

### 🪟 弹窗按钮与界面
- 修复创建媒体库、创建剧集、剧集手动匹配等弹窗中「确认 / 选择 / 创建」按钮消失的问题。
- 修复创建媒体库弹窗误显示首页轮播大图的问题。
- 修复轮播图被误注入到弹窗内部的问题。

### 🖼️ 首页轮播白屏
- 修复部分情况下首页加载时白屏卡死的问题。

### 🔗 连接与报错
- 优化 fnOS 连接 / 登录失败时的报错提示，现在能区分不同原因并给出对应的处理建议。
- 修复 Electron 安全警告未被记录到报错日志的问题。
- 报错日志现在会记录更多关键上下文信息，便于排查问题。

### 🔧 其他修复
- 修复设置面板 Bangumi 同步开关重启后显示未勾选的问题。

## ✨ 优化

- **日志文件生成逻辑优化**：单个日志文件体积更小、保留更多份数，并新增独立的报错日志文件，方便快速定位问题。
- **媒体类型匹配范围调整**：弹幕、豆瓣、Bangumi 同步现在仅针对电影、电视节目、混合影片，自动跳过电视直播与其他视频。
- **一级详情页顶部导航栏透明化**：导航栏不再遮挡背景剧照，浏览体验更沉浸。

## 🎞️ B站弹幕（MPV）优化

- 简化弹幕匹配规则，优先选择弹幕最多的单集；弹幕不足时自动合并多个候选。
- 提升匹配质量：自动回退、优先精确单集、合集自动降权。
- 弹幕较少时支持合并多个同类视频的弹幕（可在设置中调整阈值）。
- 修复 Windows 下弹幕面板中文乱码、脚本崩溃等问题，弹弹 play 限流时给出友好提示。
- 重构弹幕配置面板，手动搜索框自动填入解析到的番名。
- 弹幕匹配日志现已接入应用日志，便于排查匹配问题。
