# Fntv-Plus 更新日志

## v3.4.1-hotfix (2026-08-20)

> 本次更新修复电视直播 / 其他视频调用外置播放器失败的问题，优化界面显示与数据获取逻辑，并新增自定义界面选项与 MPV 快捷重播。

### ✨ 新功能 / 体验改进
- **新增自定义界面选项**：设置中新增「自定义界面」入口，可对界面外观进行个性化调整。
- **MPV 新增重新播放按钮**：MPV 播放器新增「重新播放」快捷按钮，一键重播当前内容。

### 🐛 修复
- **修复其他视频调用外置播放器失败**：修复部分「其他视频」调用外部播放器失败的问题。
- **修复电视直播源调用外置播放器失败**：修复播放电视直播源（黑屏 / 无法播放）调用外部播放器失败的问题。
- **修复主进程热补丁加载失败**：修复旧版本无法正确加载主进程补丁的问题，使热补丁可正常生效（含直播绕过逻辑）。

### 🔧 优化
- **优化深浅模式卡片显示**：优化浅色 / 深色主题下卡片的显示样式，文字与背景对比更清晰。
- **优化每日放送卡片数据获取**：优化「每日放送」卡片的数据获取逻辑，加载更稳定、刷新更及时。
- **优化首页轮播图加载显示**：优化首页轮播图的加载与展示效果，切换更流畅。
- **优化轮播图海报兜底**：轮播图海报获取失败时显示更友好的占位图，不再出现裂图或空白。
- **优化设置页面按钮显示**：优化设置页面部分按钮的显示逻辑，减少误触与显示异常。
