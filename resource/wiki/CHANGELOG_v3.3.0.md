# 更新日志

## v3.3.5（2026-08-04）

> 本次更新主打「每日放送」浮窗与接口限流保护，重点如下。

### 🔥 1. 新增「每日放送」浮窗（热门剧更新）
- 首页新增悬浮「🔥 每日放送」入口，点击展开液态玻璃面板，聚合展示正在放送 / 热门影视。
- 支持三数据源切换：**Bangumi**（每日放送）、**TMDB**（最新电影 / 剧集）、**豆瓣**（热门电影 / 剧集）。
- **默认数据源改为豆瓣**：国内直连、零配置免 Key，天然规避 TMDB 被墙问题；设置页可一键切回 TMDB。
- 卡片支持「不感兴趣」屏蔽与「打开详情」跳转豆瓣 / Bangumi。

### 🛡️ 2. 接口限流保护（本地持久化缓存）
- 三个数据源的列表数据接入每日磁盘缓存（`userData/cache/`）：同一数据 24 小时内最多请求线上一次，其余读取本地缓存，**跨软件重启也命中**，避免被第三方接口限流 / 封禁。
- 抓取失败不缓存；网络抖动时降级返回旧缓存，浮窗当天仍有数据可看。
- 浮窗底部显示「数据更新于 HH:MM」（跨天显示 `M/D HH:MM`），命中缓存时标注「· 本地缓存」。
- 新增「↻ 刷新」按钮：主动绕过缓存、强制重新拉取当前数据源并覆写缓存（仅用户点击才真正打接口，日常自动刷新仍走缓存）。

### 🏠 3. 浮窗仅首页显示
- 「每日放送」浮窗只在飞牛首页（`/v`）显示，进入详情 / 播放 / 搜索 / 列表等页面自动隐藏，不再遮挡内容。

## v3.3.0（2026-07-25）

> 相对 v3.2 的变更。本次更新围绕「播放器能力」与「跨平台进度同步」两大方向，重点如下。

### 🎬 1. 新增 PotPlayer 播放器支持

- **内置 PotPlayer 外部播放器**，随安装包一并分发，开箱即用。
- **播放控制**：支持续播、外挂字幕。
- **逐集连播与进度回写**：内置 `potctl.exe` 每 5 秒读取播放进度回写续播点，并支持逐集自动连播。
- **配置隔离（便携模式）**：首次使用将内置 PotPlayer ，支持用户自定义路径，使用本机配置。


### 🎞️ 2. MPV 播放器优化，新增滤镜

- **默认着色器面板**：设置页可直接选择 MPV 默认滤镜（共 10 档：关闭 / 锐化 A·B / 抗锯齿 AA·BB / 轻量 / 降噪 / 真实感 / 影院 / 极致；内置 Anime4K 等画质滤镜），出厂默认「关闭」。
- **自动获取 B站番剧弹幕**：安装包内置精简便携版 Python，无需本机安装 Python 即可自动获取 B站弹幕。
- **修复匹配失败**：修复番名以「你们」开头（如《你们先走我断后，于是10年后我成为了传说》）时被过滤规则误杀、导致弹幕为空的问题，此类番剧现已可正常获取。

### 📚 4. 影视观看进度同步豆瓣

- **在看同步**：开始播放影视后，自动将对应条目标记为豆瓣「在看」。
- **看过同步**：飞牛「已观看列表」中的影视，自动同步为豆瓣「看过」。

### 📺 5. 番剧进度同步 Bangumi 点格子

- **集数级同步**：与豆瓣「整部标看过」不同，Bangumi 精确到**单集**——播放达到阈值（默认 80%）即把该集标记为「看过」，同时把所属条目标记为「在看」。
- **完结同步**：最后一集或整部已看完时，自动将条目标记为「看过」。
- **自动映射**：按番剧名在 Bangumi 搜索匹配条目与对应集数，首次标记前自动收藏条目，避免写入失败。
- **授权**：需在设置页填入 Bangumi Token。

### ✨ 其他体验优化

- **播放按钮交互重做（按页面区分）**
  - 任意界面（卡片 / 列表）点击播放按钮 → 弹出「飞牛原生播放 / 外部播放器」**二选一**选择框；
  - 剧集 / 单集详情页 → 显示「原生 + 外部」**双按钮**并排，各播各的；
  - 开启「隐藏原生播放按钮」时 → 直接走默认外部播放器，无弹窗。
  - 切换 MPV / PotPlayer 后，外部播放按钮标签**即时刷新**。
