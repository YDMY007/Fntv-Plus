## 一、使用文档

### 1.1 什么是「插件」面板

打开设置面板（侧栏「⚙ 设置」），左侧分类导航里新增了 **「插件」** 分类。

「插件」是把 **MPV 播放器内置 Lua 脚本能力**封装成 **GUI 可控开关 / 选项**的统一入口。飞牛影视的 MPV 便携配置（`third_party/fntv-mpv/portable_config/scripts/`）里自带多个脚本套件（如 `smart_skip`、`uosc_danmaku`），原本只能在 MPV 播放时通过屏上菜单调整；插件机制让它们在客户端的设置面板里也能配置，并且可以持久化、跨会话生效。

### 1.2 已内置插件：跳过片头片尾

- **功能**：自动为影片 / 剧集加载「跳过片头 / 片尾」数据，免去手动拖动进度条。
- **数据来源（全自动，无需用户配置）**：
  1. **飞牛影视服务器跳过数据**：在 fnOS 上对影片手动设置过片头 / 片尾的，直接生效；
  2. **theintrodb 兜底**：服务器无数据时，按影片的 TMDB id 查询公开数据库 [theintrodb](https://theintrodb.org) 获取片头 / 片尾区间。
- **两种工作模式**（由「插件」面板里的「自动跳过片头片尾」开关控制）：

  | 开关状态 | 行为 |
  |----------|------|
  | **关闭（默认）** | 播放进入片头 / 片尾区间时，画面**右下角出现「跳过片头 / 跳过片尾」按钮**；点击即跳；离开该区间按钮自动消失。不打断播放，适合想自己掌控的用户。 |
  | **开启** | 到达片头 / 片尾起点时 **MPV 自动跳过**，无需点击。 |

- **使用步骤**：
  1. 打开 设置 → **插件** → 跳过片头片尾；
  2. 按需打开「**自动跳过片头片尾**」；
  3. 关闭设置面板，播放任意影片 / 剧集即可。

### 1.3 常见问题

- **Q：为什么有的影片没有「跳过」按钮？**
  A：该影片在飞牛服务器没有跳过数据，且 theintrodb 也未收录（或影片没有 TMDB id）。可先在飞牛 Web 端手动标记片头 / 片尾，或等待数据库补充。

- **Q：开关打开后还需要点按钮吗？**
  A：开启自动跳后无需点击，到达即跳；关闭则只显示按钮、由你决定是否跳。

- **Q：这个开关和 MPV 播放器里 uosc 菜单的跳过设置冲突吗？**
  A：不冲突。应用内开关是官方控制面；uosc 菜单齿轮也能改同一份 `smart_skip.conf` 的 `enabled`。应用**只在你切换面板开关时**才写入该文件，不会在启动时覆盖你在播放器菜单里的设置。

- **Q：为什么之前（旧版本）跳过功能好像没起作用？**
  A：旧版 `smart_skip/api.lua` 里代理端口写死为 `22345`，而 Go 代理实际监听 `127.0.0.1:22346`，导致飞牛服务器跳过数据一直连不上。`lc-313` 已修正为 `22346`。

## 二、开发文档

### 2.1 插件架构总览

一个「应用内插件」由四部分组成，全部约定式、无需中心化注册清单：

```text
 src/main/handlers/plugins/<name>.ts    ① 主进程插件：注册 IPC，桥接配置与 mpv conf
 src/modules/fn_config/config.ts        ② 配置持久化：开关字段 + 读写函数（双导出）
 src/main/handlers/plugins/mpvConfig.ts ③ mpv conf 双写：把开关落到 MPV 的 script-opts/*.conf
 src/preload/plugins/embyWall.ts        ④ 设置 UI：在「插件」面板渲染开关
```

数据流：`设置面板开关` → `embyWall.ts`（渲染端 `ipcRenderer.invoke`）→ `插件 IPC` → `config.ts`（写 config.json）+ `mpvConfig.ts`（双写 conf）→ MPV 脚本读取 conf 生效。

### 2.2 快速开始（四步法）

1. **新建主进程插件** `src/main/handlers/plugins/<name>.ts`，导出 `init()`，在其中用 `registerHandler` 注册 `get` / `set` 两个 IPC。
2. **config.ts**：加开关字段 + 读写函数，并**同时**补进 `module.exports`。
3. **mpvConfig.ts**：加 conf 双写辅助函数，并**同时**补进 `module.exports`。
4. **embyWall.ts**：用 `section()` 建一个区块，往 `cats` 数组的「插件」分类 `els` 追加。

完成后 `tsc` 编译（**不要**加 `--noEmit`），让 `dest/` 下的 `.js` 被更新，再用 `dev.cmd` 启动验证。

### 2.3 各模块约定详解

#### ① 插件自动加载（`src/main/handlers/plugins/`）

目录被启动时扫描，每个插件文件必须 `export { init }`。`init()` 内通过 `registerHandler(channel, handler, { useHandle: true })` 注册——`useHandle: true` 对应 `ipcMain.handle`，因此渲染端可以用 `ipcRenderer.invoke(channel, ...)` 并**拿到返回值**。新建文件无需修改任何加载清单。

#### ② 配置双导出（`src/modules/fn_config/config.ts`）⚠️ 最容易踩坑

运行期通过 CommonJS `require('../modules/fn_config/config')` 调用，因此新函数**必须同时**写成：

- `export function getXxx() {...}`（供 ESM / 类型推导）；
- **并且**在文件末尾 `module.exports = { ... }` 块里追加 `getXxx,` / `setXxx,`。

只写 `export function` 而漏掉 `module.exports`，运行时会报 `fnConfig.getXxx is not a function`。

#### ③ mpv conf 双写（`src/main/handlers/plugins/mpvConfig.ts`）⚠️ 同样双导出

MPV 在**便携模式**读 `getPortableConfigDir()`（`portable_config`），在**标准模式**读 `getMpvConfigDir()`（用户配置目录 `AppData/Roaming/mpv`）。只写一处会导致另一模式下该选项静默失效（lc-094 着色器单写不生效的教训）。新写函数一律照 `writeBiliSearchEnabled` / `writeSmartSkipEnabled` 抄：遍历两个目录、仅替换目标键行、追加注释、其余选项保留。函数也要加进 `module.exports`。

#### ④ 设置 UI（`src/preload/plugins/embyWall.ts`）

`buildSettingsPanel()` 内：

- `section(label)` 返回 `{ el, body }`——`el` 是整张卡片、`body` 是卡片内容容器；
- 顶层左侧导航是 `cats: Cat[]` 数组（`{ id, label, els: HTMLElement[] }`）。加面板 = 新建一个 `section` 区块 + 把其 `el` 追加到「插件」分类的 `els`（若该分类不存在则新增一条 `{ id:'plugins', label:'插件', els:[...] }`）。
- 开关用 `ipcRenderer.invoke('settings:get-x', ...)` 读初始值、`settings:set-x` 写回，并包 `.catch(...)` 防报错。

> ⚠️ `embyWall.ts` 是一个巨大的单文件（3000+ 行），**不要大段重写**；只插入一个新 `section` 块 + 一条 `cats` 条目即可。

### 2.4 完整范例：smartSkip 插件

**① `src/main/handlers/plugins/smartSkip.ts`**

```ts
import { IpcMainInvokeEvent } from 'electron';
import * as fnConfig from '../../../modules/fn_config/config';
import { writeSmartSkipEnabled } from './mpvConfig';
import { registerHandler } from '../core/ipcHandler';

function handleGetSmartSkipEnabled(): boolean {
    return fnConfig.getSmartSkipEnabled();
}

function handleSetSmartSkipEnabled(_event: IpcMainInvokeEvent, enabled: boolean): void {
    const val = !!enabled;
    fnConfig.setSmartSkipEnabled(val);   // 落 config.json
    writeSmartSkipEnabled(val);          // 双写 smart_skip.conf
}

function init(): void {
    registerHandler('settings:get-smart-skip-enabled', handleGetSmartSkipEnabled, { useHandle: true });
    registerHandler('settings:set-smart-skip-enabled', handleSetSmartSkipEnabled, { useHandle: true });
}

export { init, handleGetSmartSkipEnabled, handleSetSmartSkipEnabled };
```

**② `config.ts`（节选）**

```ts
// 接口字段
smartSkipEnabled?: boolean;

// 读写函数
export function getSmartSkipEnabled(): boolean {
    const config: Config = readConfig() || {};
    return config.smartSkipEnabled === true;   // 默认关闭
}
export function setSmartSkipEnabled(enabled: boolean): void {
    const config: Config = readConfig() || {};
    config.smartSkipEnabled = !!enabled;
    fs.writeFileSync(getConfigPath(), JSON.stringify(config, null, 2));
}
// ⚠️ 末尾 module.exports = { ... } 内还要加：
//   getSmartSkipEnabled, setSmartSkipEnabled,
```

**③ `mpvConfig.ts`（节选，双写核心）**

```ts
export function writeSmartSkipEnabled(enabled: boolean): void {
    try {
        const val = enabled ? 'yes' : 'no';
        const dirs = [getPortableConfigDir(), getMpvConfigDir()];   // 双目录
        for (const dir of dirs) {
            try {
                const scriptOptsDir = path.join(dir, 'script-opts');
                if (!fs.existsSync(scriptOptsDir)) fs.mkdirSync(scriptOptsDir, { recursive: true });
                const target = path.join(scriptOptsDir, 'smart_skip.conf');
                let lines: string[] = [];
                if (fs.existsSync(target)) lines = fs.readFileSync(target, 'utf-8').split(/\r?\n/);
                lines = lines.filter(l => !/^\s*enabled\s*=/.test(l) && !/^#\s*智能跳过片头片尾开关/.test(l));
                while (lines.length && lines[lines.length - 1].trim() === '') lines.pop();
                lines.push('# 智能跳过片头片尾开关（由应用「插件」面板控制）');
                lines.push('enabled=' + val);
                fs.writeFileSync(target, lines.join('\n') + '\n', 'utf-8');
            } catch (e) { logger.error(`写入 smart_skip.conf 失败: ${dir}`, e); }
        }
    } catch (error) { logger.error('写入 smart_skip.conf 失败:', error); }
}
// ⚠️ 末尾 module.exports 内还要加：writeSmartSkipEnabled,
```

**④ `embyWall.ts`（节选，设置区块 + 分类）**

```ts
const secSkip = section('跳过片头片尾');
const skipDesc = document.createElement('div');
skipDesc.textContent = '自动加载飞牛/影片库跳过数据；可在播放时显示「跳过片头/片尾」按钮，或开启后自动跳过。';
skipDesc.style.cssText = 'color:#9aa0a6;font-size:12px;line-height:1.5;margin-bottom:6px;';
secSkip.body.appendChild(skipDesc);

const swSkip = document.createElement('input');
swSkip.type = 'checkbox';
swSkip.style.cssText = 'width:38px;height:21px;cursor:pointer;accent-color:var(--fnos-ui-accent);';
swSkip.addEventListener('change', () => {
    ipcRenderer.invoke('settings:set-smart-skip-enabled', swSkip.checked).catch((err) => log('set failed', err));
});
secSkip.body.appendChild(swSkip);
// 读初始值
ipcRenderer.invoke('settings:get-smart-skip-enabled').then((v: boolean) => { swSkip.checked = !!v; }).catch(() => { swSkip.checked = false; });

// 在 cats 数组里挂到「插件」分类
const cats: Cat[] = [
  // ... 其他分类 ...
  { id: 'plugins', label: '插件', els: [secSkip.el] },
];
```

### 2.5 注意事项与坑

1. **config.ts 与 mpvConfig.ts 都要「双导出」**：ESM `export` + `module.exports`，漏掉任一都会导致运行期 `is not a function`。
2. **mpv conf 必须双写** `portable_config` 与用户配置目录两处，否则换模式后选项失效。
3. **不要在 `init()` 启动时把 config 值强制写回 conf**：若某 mpv 选项也能在 uosc 屏上菜单里改，启动覆盖会抹掉用户在菜单里的选择。只在面板开关变化时写（如 `smartSkip.ts`）。
4. **保持 IPC 边界干净**：属于主进程的逻辑不要塞进 `embyWall.ts`；UI 只负责渲染与调用 `invoke`。
5. **改完必须 `tsc`  emits 到 `dest/`**：加载器读编译产物不读 `src/`。验证用 `dev.cmd`（它会先 `taskkill` 旧进程再 `tsc` 再启动）。
6. **提交约定**：本项目改动自动本地 `commit` + 打 `lc-NNN` 标签，默认不 `push`；dev 运行时产物（`mpv-user.conf`、各类 conf、`proxy.exe`）不入库。
