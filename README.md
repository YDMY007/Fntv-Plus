# Fntv-Plus飞牛影视桌面客户端 · 增强版（fpk · Web 版）

为飞牛影视（fnOS TV）网页端打造的**轻量化界面增强插件**——一个 fpk 应用包装进 fnOS，浏览器打开影视页面即享全部增强，无需在每台设备上安装任何软件。

> 想要完整桌面体验（MPV 硬解、原盘播放、更多全量功能）？请前往桌面客户端仓库：**https://github.com/YDMY007/Fntv-Plus**

---

## 这是什么

Fntv-Plus 有两个形态：

- **桌面客户端**（Windows 安装包）：功能最全的本地播放器方案；
- **Web 版（本仓库，fpk）**：把增强能力直接注入到 fnOS 影视网页端——**更轻量、部署更简单**，装一次，全家所有设备（电视 / 平板 / 手机 / 电脑浏览器）打开飞牛影视网页就是增强版。

Web 版后端是一个 **Go 静态编译的单二进制**（约 14MB），零运行时依赖——不需要 Node.js、不需要 Python、不碰任何系统文件。

> **本应用为个人练手作品，与飞牛/fnOS 及官方影视应用无任何隶属关系**；不改任何系统文件，卸载即完全还原。

## 安装与使用

1. 在 fnOS 应用中心选择「手动安装」，上传 fpk 包；安装向导中确认**服务端口**（默认 22350）与**飞牛影视 Web 端口**（默认 5666）；
2. fnOS 桌面会出现「Fntv-Plus」图标，**点击即进入增强后的影视页面**；
3. 侧栏设置面板（⚙）：增强开关 / 账号与网络 / 弹幕 / 诊断与实时日志；
4. 卸载时可选**保留数据**（重装自动恢复设置与缓存）或**删除数据**。

## 已有功能

### 界面增强
- **海报墙美化**：首页海报墙 / 分类页沉浸式视觉优化（毛玻璃 / 圆角 / 白斑修复）
- **首页轮播图**：4 种样式可切换（含 3D 立体旋转木马），TMDB 数据驱动；手机尺寸自动适配
- **轮播标题替换为 Logo**：自动拉取 TMDB 透明标识替换文字标题
- **首页 Logo 自定义**：24 个流媒体平台预设（Netflix / Disney+ / 爱奇艺 / B站…）或上传自己的图片
- **详情页美化**：沉浸底图 / 两栏布局 / 磨砂卡片，可一键回退原生；序号视图（纯数字选集）同享美化
- **TMDB 增强**：详情页评分 / 演员作品 / 每日放送（Bangumi / TMDB / 豆瓣）
- **豆瓣同步**：评分与标记同步（在看/看过，反代端口级增强）

### 播放与弹幕
- **弹幕系统**（网页播放器 canvas 渲染）：B站弹幕（番剧 / 影视 / 视频区三路搜索，扫码登录态）+ 自建 danmu_api 优选源 + **手动搜索候选**（自建源与B站候选并存）
- **手机网页弹幕**：弹幕按钮点按开合（触屏 toggle）、面板自适应窄屏、手机字号优化
- **播放页底栏触控适配**：触控热区/字号/间距/进度条触控带按手机优化
- **弹幕设置**：样式（字号 / 描边 / 透明度 / 显示范围）/ 屏蔽类型与屏蔽词，飞牛原生风格弹窗
- **弹幕接口分层诊断**：地址形态 → DNS → TCP → TLS → 服务应答逐层归因
- **跳过片头**（基于 fnOS skipinfo）
- **播放记忆**：续播进度跨设备同步

### 观影与工具
- **观影记录**：侧边栏面板，含年度观影报告
- **库索引 / 已入库角标**：item/list API 主源，全库快速索引
- **自定义刮削源回填**（季页「⟳ 自定义刮削」按钮）：把视频标题/季号/TMDB id 等锚点发给你的自定义刮削服务，返回的分集标题与简介经飞牛官方接口回填元数据——不改系统文件，精确锚点匹配（tmdb_id > trim_id > imdb_id > douban_id）
- **自定义刮削服务**（设置面板占位）：多源聚合接入，开发中
- **诊断与实时日志**：版本 / 上游连通性 / 各开关状态一目了然，内嵌实时日志视图

### 手机适配
- **详情页窄屏单列**：选集 / 信息卡 / 演职人员纵向堆叠，触屏设备自动生效
- **播放页底栏触控适配**：按钮热区 / 字号 / 进度条触控带按手机优化
- **轮播手机模式**：纯海报画面（文字层隐藏）、卡片不出屏、竖屏高度自适应

### 部署特性
- **零依赖**：静态编译 Go 二进制，不需要 Node.js / Python / 数据库
- **零侵入**：不改任何系统文件，卸载可选保留或删除数据
- **轻量入口**：桌面图标 = 直达影视页；管理页独立入口不占桌面

## Web 版 vs 桌面客户端

| 功能 | Web 版（fpk） | 桌面客户端 |
|---|:---:|:---:|
| 部署方式 | fnOS 应用中心装一次，全设备浏览器即用 | Windows 安装包，每台 PC 各装一份 |
| 运行环境 | 无（NAS 端静态二进制） | Windows 10/11 |
| 海报墙 / 详情页美化 | ✅ | ✅ |
| 首页轮播图（4 种样式） | ✅ | ✅ |
| 轮播 Logo / 首页 Logo 自定义 | ✅ | ✅ |
| B站弹幕 + 自建源优选 + 手动搜索 | ✅ | ✅ |
| 手机网页适配（单列详情/触控弹幕/底栏） | ✅ | — |
| 每日放送（Bangumi/TMDB/豆瓣） | ✅ | ✅ |
| 豆瓣同步 / Bangumi 同步 | ✅ | ✅ |
| 自定义刮削源回填 | ✅ | ❌ |
| 跳过片头 | ✅（网页播放器） | ✅（MPV） |
| 观影记录 + 年度报告 | ✅ | ✅ |
| 播放记忆续播 | ✅ | ✅ |
| 管理页 | ✅ | ✅ |
| MPV / PotPlayer 外部播放器 | ❌ | ✅ |
| 硬件解码 / 原盘 / 高级字幕 | ❌ | ✅ |
| Trakt 同步 / 手柄遥控 | ❌ | ✅ |
| 播放器内缩略图预览 | ❌ | ✅ |

> **选型建议**：主要用电视 / 平板 / 手机看飞牛影视，追求省心 → **Web 版**；主要在 Windows PC 上看大片、需要 MPV 硬解与原盘能力 → **桌面客户端**。两者可共存，数据互不干扰。

## 版本说明

| 通道 | 版号规则 | 产物 | 打包方式 |
|---|---|---|---|
| **开发测试版**（小写 v） | `0.9.<commit数>` 时代已迁移：`<正式版基号>.<commit数>` 四段式，如 `1.0.0.201` | `Fntv-Plus-v<commit数>.fpk` | 双击 **一键打包.bat** |
| **正式发布版**（大写 V） | 用户在网页上填写的正式版号（飞牛商店显示） | `Fntv-Plus-V<版号去点>.fpk` | 双击 **发布打包.bat** → 网页操作 |

- 测试包与正式包互相覆盖关系：测试包 `1.0.0.x` > 正式 `1.0.0`（可覆盖已装正式版）；下一正式 `1.0.1` > 测试 `1.0.0.x`（正式迭代不被挡）；
- 从源码构建依赖：Node.js（前端 payload）+ Go 1.23+（后端）+ fnpack（飞牛官方打包工具，放 `tools/fnpack.exe`）。
